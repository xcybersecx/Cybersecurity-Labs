# Package Manifest

This package contains the written GitHub documentation for the existing repository folder.

- `README.md` - full chronological assessment, all 61 screenshots referenced, four core ports, additional testing, troubleshooting, findings, remediation, limitations and reflection.
- `EVIDENCE-INDEX.md` - one-row-per-screenshot evidence map covering all 61 screenshots.
- `LEARNING-NOTES.md` - concept-focused notes explaining the commands, module workflow and lessons from the exercise.
- `UPLOAD-INSTRUCTIONS.txt` - simple upload instructions.

The screenshot files themselves are not duplicated in this ZIP because they are already present in the GitHub repository under `Metasploit 11-09-26/` and the Markdown links point to that existing folder.
