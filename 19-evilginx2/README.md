## Assignment overview

This repository documents practical exploration of a Kali Linux lab, YAML/phishlet file inspection in VS Code (Code - OSS), browser cookie management tools, virtual network configuration, and access to a deliberately vulnerable training application (DVWA).

Evilginx2 is a dual-use security testing framework. This record is for supervised, authorized lab study only. It contains **screenshots rather than a deployable phishlet, captured cookies, session tokens, or credentials**.

## Learning points

- YAML indentation, mapping keys, and configuration structure require careful review.
- Browser cookie tools can be studied safely using non-sensitive lab data.
- VM network mode, DNS, and reachability affect whether local security tools and lab targets work.
- DVWA is an intentionally vulnerable training application and should remain inside an authorized environment.

## Scope and limitations

The screenshots evidence an exploratory session, including troubleshooting. They **do not establish a successful Evilginx2 deployment, live authentication interception, or full completion of every assignment objective**. No claim of testing a real third-party site is made.

## Safety and ethics

All activity is described as coursework in a controlled environment. Do not use security testing tools against systems, services, or accounts without explicit authorization.
